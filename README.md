# Lovelace

Repositorio de pipelines para classificacao documental com LLM, incluindo:

- RVL-CDIP OCR -> LLM (`src/rvl_text_pipeline`)
- RVL-CDIP QLoRA supervisionado (`src/rvl_qlora_train` e `scripts/qlora`)
- JurisTCU TIPOPROCESSO supervisionado (`scripts/juristcu_tipoprocesso_pipeline`)
- Projeto piloto sem supervisao humana (`Lovelace_old_Sem_Supervisão_Humana`)
